# Contributing

Thanks for improving ChatGPT Auto Allow Tool.

## Local Checks

Run:

```bash
npm run check
```

This checks JavaScript syntax and validates required manifest files.

## Pull Request Checklist

- Keep host permissions limited to ChatGPT domains unless there is a clear reason.
- Update `README.md` when behavior or installation steps change.
- Update `CHANGELOG.md` for user-visible changes.
- Avoid collecting or transmitting user data.
- Do not include private ChatGPT conversations, cookies, tokens, or screenshots with secrets.

## Coding Style

This project intentionally uses plain JavaScript and no build step. Keep changes small and readable.
