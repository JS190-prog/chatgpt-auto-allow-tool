# ChatGPT 연결 플러그인 전체 새로고침 계획

## 목적

확장 프로그램 팝업의 버튼을 한 번 누르면 ChatGPT에 현재 설치·연결된 플러그인을 이름과 개수에 관계없이 확인하고, 상세 화면에 `새로 고침` 기능이 있는 항목만 순차적으로 새로고침한다.

이 문서는 2026-07-28의 실제 ChatGPT 웹 UI와 현재 `allowautoclick` 0.2.0 코드를 기준으로 한다. UI가 바뀌면 선택자 계약도 함께 갱신해야 한다.

## 실측한 현재 구조

### ChatGPT

1. `https://chatgpt.com/plugins#settings/Plugins`에서 설정 대화상자가 열린다.
2. `플러그인` 탭의 `설치한 플러그인을 관리합니다` 영역에는 설치된 플러그인이 버튼 목록으로 표시된다.
3. 현재 계정에서는 24개가 확인됐다. 따라서 MCPWorld의 기존 7개 이름을 고정 목록으로 두면 누락·오선택이 생긴다.
4. 목록 항목을 누르면 URL 해시가 `#settings/Plugins/<plugin-id>`로 바뀌고 같은 설정 대화상자 안에 상세 화면이 열린다.
5. 연결형 플러그인의 상세 화면에는 다음 요소가 있다.
   - 플러그인명과 `연결됨` 상태
   - `이전` 버튼
   - `정보` 영역의 `새로 고침` 버튼
   - `플러그인 작업` 메뉴의 `연결 해제` 항목
6. `1. office`에서 `새로 고침`을 실제로 한 번 눌러 확인했다.
   - 확인창은 나타나지 않았다.
   - 상세 화면과 URL은 유지됐다.
   - 처리 중 `새로 고침` 버튼에 `disabled` 속성이 생겼다.
   - 약 8.5초 뒤 `disabled` 속성이 사라졌다.
   - 따라서 클릭 성공이 아니라 버튼의 `활성 → 비활성 → 활성` 전이를 완료 조건으로 써야 한다.
7. 상세 화면의 `이전` 버튼은 정보 영역보다 먼저 렌더링될 수 있다. `새로 고침` 또는 `정보`가 나타날 때까지 기다린 뒤 대상 여부를 판별하고, 둘 다 없는 상세는 제한 시간 후 오류가 아닌 정상 건너뜀으로 처리한다.

### 현재 확장 프로그램

- `content.js`는 권한 카드의 허용 버튼을 찾는 `scan()`을 MutationObserver와 1초 타이머로 계속 실행한다.
- 실제 클릭 동작은 기존 `clickLikeUser()`가 담당한다.
- `popup.js`는 자동 허용 켜기/끄기와 옵션 열기만 제공한다.
- `manifest.json`은 `storage` 권한만 사용한다.
- 새로고침 기능은 아직 없으며, 기존 자동 허용 검색과 섞으면 일반 페이지의 다른 `새로 고침` 버튼을 누를 위험이 있다.

## 확정 설계

### 사용자 흐름

1. 사용자가 ChatGPT 탭에서 확장 프로그램 팝업을 연다.
2. `연결 플러그인 전체 새로고침`을 누른다.
3. 현재 탭이 ChatGPT인지 확인한다.
4. 콘텐츠 스크립트가 설정의 플러그인 목록을 연다.
5. 설치된 항목을 현재 DOM에서 동적으로 수집한다.
6. 각 항목을 하나씩 열어 `새로 고침` 버튼이 있는지 확인한다.
7. 버튼이 있으면 한 번 누르고 완료 전이를 기다린다. 없으면 건너뛴다.
8. `이전`으로 목록에 돌아와 다음 항목을 처리한다.
9. 팝업에 `완료 n / 대상 m / 건너뜀 k` 또는 실패한 항목을 표시한다.

### 대상 판별

이름, 번호, 플러그인 ID를 코드에 고정하지 않는다.

- 목록 범위: 설정 대화상자의 `플러그인` 탭 안, 설명문 `설치한 플러그인을 관리합니다` 다음의 플러그인 항목 버튼들
- 새로고침 대상: 상세 화면에서 정확한 접근성 이름 `새로 고침` 또는 `Refresh`를 가진 버튼이 하나만 존재하고, 같은 상세 화면에 연결 상태가 표시되는 항목
- 제외: `플러그인 작업`, `연결 해제`, 설정 닫기, 일반 페이지의 새로고침, 권한 허용 버튼

목록을 처음에 DOM 요소로 저장하지 않고 플러그인명과 상세 URL 식별자만 값으로 복사한다. 화면 전환 때 React가 요소를 다시 만들기 때문에 오래된 DOM 참조는 쓰지 않는다.

### 순차 상태기

```text
IDLE
  → OPEN_SETTINGS
  → COLLECT_INSTALLED
  → OPEN_DETAIL(i)
  → FIND_REFRESH
      ├─ 없음 → SKIP(i)
      └─ 있음 → CLICK_ONCE
                  → WAIT_DISABLED
                  → WAIT_ENABLED
  → BACK_TO_LIST
  → 다음 항목 또는 DONE
```

- 병렬 클릭은 하지 않는다.
- 항목당 클릭은 최대 한 번이다.
- `WAIT_DISABLED`는 클릭이 실제로 접수됐음을 확인한다.
- `WAIT_ENABLED`는 완료 신호다.
- 각 대기는 MutationObserver 기반으로 하고 안전 타임아웃을 둔다. 1초 폴링 타이머를 추가하지 않는다.
- 예상하지 못한 확인창, 대상 버튼 중복, 목록 복귀 실패가 나오면 즉시 중단하고 부분 결과를 반환한다.
- 실행 중 팝업 버튼은 비활성화해 중복 실행을 막는다.

## 최소 변경 범위

| 파일 | 변경 |
|---|---|
| `popup.html` | 전체 새로고침 버튼과 상태 한 줄 추가 |
| `popup.js` | 활성 ChatGPT 탭에 시작 메시지를 보내고 진행/결과 표시 |
| `popup.css` | 새 버튼의 기존 스타일 재사용, 실행 중 상태만 추가 |
| `content.js` | 목록 수집, 상세 판별, 순차 새로고침 상태기 추가. 중복 `click` 이벤트가 없는 1회 클릭 보조 함수 사용 |
| `scripts/validate-plugin-refresh.js` | 외부 라이브러리 없이 대상 수집·상태 전이의 작은 회귀 검사 추가 |
| `package.json` | 기존 `npm run check`에 위 검사 연결 |

기존 ChatGPT 호스트 권한으로 팝업과 콘텐츠 스크립트가 통신할 수 있어 새 권한은 추가하지 않는다. 백그라운드 서비스 워커, 이름 설정 화면, 영구 작업 큐, 재시도 저장소도 필요 없다.

## 실패 처리

- ChatGPT가 아닌 탭: `ChatGPT 플러그인 화면에서 실행하세요`로 종료
- 설정을 열 수 없음: 클릭 없이 종료
- 설치 항목 없음: 0건 결과 표시
- 상세 화면에 새로고침 없음: 정상 건너뜀
- 클릭 뒤 비활성 전이가 없음: 해당 항목 실패로 중단
- 완료 타임아웃: 해당 항목과 완료된 개수를 표시하고 중단
- UI 언어 변경: `새로 고침`과 `Refresh`만 지원하고, 다른 모호한 단어는 추측해 클릭하지 않음
- 팝업을 닫아도 콘텐츠 스크립트 작업은 계속되며, 다시 열면 현재 페이지의 실행 상태를 질의해 표시

## 검증 계획

### 자동 검사

1. 이름과 개수가 다른 가짜 설치 목록을 주면 모두 수집한다.
2. 상세 화면에 새로고침 버튼이 있는 항목만 클릭 대상으로 판별한다.
3. `3. opencrab` 같은 유사 이름도 이름 필터 없이 독립 항목으로 처리한다.
4. 일반 페이지의 `새로 고침`, `연결 해제`, `허용` 버튼은 대상이 되지 않는다.
5. 한 항목을 두 번 클릭하지 않는다.
6. `활성 → 비활성 → 활성` 전이가 없으면 성공 처리하지 않는다.
7. `npm run check`와 `git diff --check`가 통과한다.

### 실제 브라우저 검사

1. 별도 테스트 플러그인 1개로 단일 새로고침과 완료 전이를 재확인한다.
2. 전체 실행 전 설치 항목 수를 기록한다.
3. 전체 실행 후 결과의 `대상 + 건너뜀`이 설치 항목 수와 일치하는지 확인한다.
4. 새로고침 대상은 각각 정확히 한 번만 처리됐는지 진행 기록으로 확인한다.
5. 새 채팅에서 대표 MCPWorld 플러그인의 최신 도구/버전이 보이는지 확인한다.

## 완료 기준

- 플러그인 이름이나 7개라는 개수에 의존하지 않는다.
- 현재 연결된 목록 전체를 검사한다.
- 새로고침 기능이 있는 모든 항목을 순차적으로 한 번씩 처리한다.
- 완료 전이를 확인한 뒤에만 성공 건수를 올린다.
- 다른 버튼을 누르지 않는다.
- 실패 시 완료된 범위와 중단 원인이 사용자에게 보인다.

## 범위 밖

- ChatGPT 내부 비공개 API 직접 호출
- 플러그인 연결/연결 해제 자동화
- 브라우저 시작 시 자동 실행
- 주기적 백그라운드 새로고침
- 특정 MCPWorld 플러그인 이름 목록 유지

이 기능은 ChatGPT DOM에 의존하는 보조 자동화다. 공식 일괄 새로고침 API가 제공되면 DOM 자동화 대신 그 API로 교체한다.
